# The Goofy Fish Tank

The Goofy Fish Tank is an interactive aquarium project created using HTML, CSS, and JavaScript. It displays a virtual fish tank with animated fish, bubbles, plants, rocks, and a food jar. The project focuses on creating a simple and fun user experience through web development.

The first key function is the fish movement system. JavaScript creates multiple fish objects that can swim around the tank, move in different directions, and react to their surroundings. Fish can also collide with each other and interact with the environment.

The second key function is the feeding and interaction system. Users can drag food into the tank, and fish will detect and eat the food. Users can also click and drag fish around, making the aquarium more interactive and engaging.

The third key function is the fish behavior system. Users can change a fish into an angry state, which changes how it moves and interacts with other fish. This feature shows how JavaScript can control different behaviors and animations in a webpage.
